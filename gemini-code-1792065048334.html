Conexión con Outlook y respaldo
La lectura de PDFs y la confirmación funcionan ahora. La recepción desde Outlook queda pendiente de configurar Power Automate en su cuenta Microsoft. Puede importar el JSON de extracción mediante “Seleccionar archivo”.
Flujo para configurar en Microsoft 365
  1. Recibir correo en carpeta de cotizaciones con Office 365 Outlook.
  2. Guardar el adjunto original y detectar SA sin crear una SA nueva.
  3. Extraer campos con AI Builder / OCR y construir el JSON del contrato incluido.
  4. Descargar o transferir ese JSON al equipo de revisión; esta versión permite importarlo manualmente.
  5. Revisar y confirmar en esta aplicación. Para recepción automática y varios usuarios, implementar un servicio autenticado y base central.

La eliminación no descarga archivos. Si quiere conservar una copia, use este botón antes de eliminar.
